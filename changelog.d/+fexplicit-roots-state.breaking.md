`amici::AbstractModel::fexplicit_roots` now takes the state vector as
first argument, `fexplicit_roots(x, p, k, w)`, and
`amici::Model::reinit_explicit_roots` now takes the state vector, as explicit
trigger times may now depend on state variables with zero time derivative
(#3365). This only affects users who subclass `AbstractModel`/`amici::Model`
directly in C++ or call `reinit_explicit_roots` from C++; models generated by
the SBML/PySB Python code generator only need to be regenerated.
